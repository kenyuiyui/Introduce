語音卡片筆記

說話就能變成一張一張的文字卡片。掛在 LINE 裡的個人語音筆記工具，講出來的話即時整理成可編輯的卡片。

立即使用 原始碼

Overview

類型
個人專案 · 免費 · 非商用
平台
LINE LIFF（純前端網頁，掛載於 LINE 官方帳號）
技術棧
Vanilla JavaScript · LIFF SDK · MediaRecorder API · Groq Whisper API · opencc-js
架構
單一 HTML 檔案，無後端伺服器，資料存於使用者本機 localStorage
狀態
使用中，持續依回饋調整

Specs

轉寫模型
whisper-large-v3-turbo（Groq API）
分段間隔
15 秒自動切段送出，卡片陸續生成
發送方式
3 種：送回聊天室 / LINE 好友分享 / 系統分享
編輯模式
3 種：合併句子 / 調整順序 / 修改內容
語言處理
內建簡轉繁保險（opencc-js）
存取控制
好友身份驗證（liff.getFriendship）+ 使用須知同意閘門

Features

  • 即時錄音轉寫講話同時卡片陸續生成，不用等整段錄完
  • 卡片草稿持久化自動儲存在本機，誤觸返回或切出頁面不怕內容消失
  • 共用裝置清除工具一鍵清除本機 API 金鑰與卡片內容
  • 發送前預覽模擬對話氣泡呈現，確認內容再送出

Security

  • Content-Security-Policy，限制外部資源來源網域
  • 關鍵 CDN 套件加上 SRI 完整性驗證，防範供應鏈攻擊
  • 使用前需通過好友身份驗證與使用須知同意，未通過無法進入主功能
  • 連結欄位與使用者輸入內容皆經過 HTML 跳脫處理，避免 XSS

Limitations

  • 需自行申請免費 Groq API Key，金鑰與卡片內容存於使用者裝置瀏覽器
  • 語音內容會上傳至 Groq 雲端進行轉寫，原始音檔不保留
  • 不建議用於機密或高度敏感內容（商業機密、他人個資、密碼等）
  • 個人維護，無正式客服或服務保證，可能因故調整或中止
